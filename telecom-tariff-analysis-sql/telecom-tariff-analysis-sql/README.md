# Telecom Tariff Analysis — SQL

## Project Overview

SQL analysis of customer usage and monthly spending across two telecom tariff plans.

The project focuses on preparing monthly customer activity, calculating spending based on tariff conditions, and comparing customer costs across tariff plans.

## What I Did

- Checked key data quality issues in customer and call data.
- Aggregated monthly calls, internet traffic and SMS by customer.
- Built a customer-month dataset combining all types of activity.
- Calculated usage above tariff limits.
- Calculated total monthly customer spending.
- Compared average monthly spending between tariff plans for active customers.
- Analyzed customers whose monthly spending exceeded the tariff fee.

## Tools

- PostgreSQL
- SQL
- CTEs
- JOINs
- UNION
- Conditional aggregation with `CASE`
- Temporary views

## Data

The project was completed using an educational telecom database provided during professional retraining.

The original dataset and course materials are not included in this repository.
